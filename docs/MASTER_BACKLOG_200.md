# Watchbane: мастер-бэклог 200 работ

Исходная сверка: 21 ноября 2026, [`028ff9b`](https://github.com/veitnemed/watchbane/commit/028ff9be7735e1f99900111a7bf9ee61648ff84e); последний опубликованный ориентир [Preview 5 (исходники)](https://github.com/veitnemed/watchbane/releases/tag/story-search-preview.5). Новые WB-ID не заменяют LEG-ID.

**Прежние 90:** раньше 55 закрытых / 33 частичных / 2 неподтверждённых. Теперь 53 VERIFIED / 34 PARTIAL / 3 неподтверждённых (TODO). LEG-006 и LEG-009 понижены до PARTIAL; LEG-020 перенесён из PARTIAL в TODO: свежий реальный прогон 1k/5k/10k не найден. LEG-035 и LEG-089 не закрыты. Все незакрытые критерии имеют назначенную работу WB.

**Порядок:** P0 (целостность) → P1 (каталог, поиск, первый запуск) → P2 (Windows, E5, производительность) → P3 (полировка). Зависимости в таблице задают порядок начала; дополнительные условия блокируют приёмку. TODO со ссылкой LEG — смотри уже пройденные проверки, не повторяй их ради статуса. Область VERIFIED ограничена указанным критерием и фактической платформой; новых крупных закрытий не следует считать из числа коммитов.

**Сейчас:** WB-024/025: первый атомарный бэкап, затем отдельный сбой восстановления и матрица старых профилей. WB-081/085/090: закрытый протокол независимой оценки, пока ограничен покрытием корпуса. WB-008/151: разбор давних ошибок в повторяемом окружении. Использовать существующие Issues [#12](https://github.com/veitnemed/watchbane/issues/12)–[#16](https://github.com/veitnemed/watchbane/issues/16), не дублировать сотнями задач.

Тестовый профиль Linux: Python 3.12, ORT 1.23.2, PyQt offscreen; модель FP32 по закреплённому манифесту. Запуски плана в 11:00, 15:00, 19:00, 23:00 МСК предназначены для возобновления, не для ограничения скорости. 26 ноября — контрольная сводка, не автоматическое закрытие. Публикация прерванного Preview 6 не возобновляется; новые preview только после соответствующих проверок, с честно обозначенной платформой и оформленными правами на данные.
