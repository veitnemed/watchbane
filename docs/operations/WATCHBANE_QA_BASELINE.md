- Сверка старых задач: `028ff9be7735e1f99900111a7bf9ee61648ff84e`, дерево `9f0d50cde002f4802848b1d5c236c2ae306da7a3`. Сопоставление до и после исправления восстановления: `ce99518a4d814f6f566a5ab56a6d000035fac957` и `1089cfbf5a71ffa319aa55a36da53d75198d71ca`.
- Debian 13 (Linux 6.18.57, x86-64), Python 3.12.14, Qt и PyQt 6.11.0, SQLite 3.53.1, pytest 8.4.2, ONNX Runtime 1.23.2, NumPy 2.3.5, tokenizers 0.22.2. Профили: одноразовые пустые каталоги для Qt (два процесса) и SQLite; не использовать основной профиль.
- Локальный каталог для этого прогона: 50 ранее проверенных реальных описаний, SHA-256 JSONL `2e5282f58041446e6acefe20cdef61c31089a8661e1b8542ed11c5f265b4191b`. Файл не распространяется. Для сопоставления используй тот же разрешённый набор или отдельно зафиксируй другой хеш. FP32 проверяется по [закреплённому манифесту](../../candidates/story_model_manifest.py). Каталог и модель не загружаются сценариями повторения.
- Команды (из корня чистого дерева; переменные указывают на разрешённые локальные файлы):

```sh
export QT_QPA_PLATFORM=offscreen
export WATCHBANE_TEST_MODEL_DIR="$MODEL_DIR"
python -m pytest -q --junitxml=/tmp/watchbane-tests.xml
python -m pytest -q tests/test_sqlite_backup_restore.py tests/test_sqlite_startup_recovery.py tests/test_data_profiles.py
python -m tools.qa.smoke_story_desktop --verify-cached-install \
  --catalog "$CATALOG_JSONL" --model-dir "$MODEL_DIR" \
  --query 'банкир попадает в тюрьму и годами роет тоннель' \
  --expected-title 'Побег из Шоушенка' --qt-platform offscreen
```

Чистое дерево, версии и входные хеши обязательны для сравнения. Демо измеряет запуск с уже существующей моделью, а не скачивание. Windows Server runner тестирует свои сценарии; это не чистая клиентская Windows. Прогоны не использовали TMDb-ключ, чужую коллекцию или сетевой обход.
