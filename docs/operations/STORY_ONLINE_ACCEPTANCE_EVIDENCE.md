# Watchbane: приёмка серверного поиска

Снимок доказательств на [edc4dd6](https://github.com/veitnemed/watchbane/commit/edc4dd603712b9d5bfa45f61ae921fcef6209804), 22 ноября 2026. Это журнал проверенного, не план работ. «Локально» означает HTTP на loopback, не доступный извне сервис. «50 реальных» означает разрешённый только для локального теста срез (23 фильма, 27 сериалов), не живой импорт или покрытие TMDb.

| Пакет | Статус и доказательство |
|---|---|
| **1. Сквозной прототип** | **Принят локально.** Реальная FP32 E5 на Linux/FastAPI вернула типизированные TMDb ID и описания по русскому запросу на 50 реальных записях. Инференс был на сервере; запросы не сохранялись в постоянном журнале. [Локальная проверка и ограничения](STORY_SERVER_LOOPBACK.md). |
| **2. Импорт TMDb** | **Живой этап заблокирован.** Датированные ID-файлы и очередь привязаны к хешам; типы не смешиваются. [Репетиция](../TMDB_OPERATOR_DRY_RUN.md) прошла с синтетическими HTTP-ответами, остановкой 429 и возобновлением в новом процессе. [Двухтайтловый микропробник](https://github.com/veitnemed/watchbane/commit/65d01fc6544fb6ae0858ed7255dcd350a1eb70dc) подготовлен, но ни один живой запрос им не выполнялся; 10 000 реальных описаний не получены. |
| **3. Индекс и ограниченные ресурсы** | **Частично.** На паре реальных снимков 49→50 [переиспользованы 49 векторов](https://github.com/veitnemed/watchbane/commit/48351b3ee6ed0a116d3e19ede77f33cc8c6ed525); итоговая матрица и 12 HTTP-ответов совпали с полной пересборкой. [ARM64, 2 000 синтетических строк](https://github.com/veitnemed/watchbane/actions/runs/45019936088/job/137200380799) при 2 CPU / 2 ГиБ / без swap: готовность 297,79 с без кэша и 8,12 с с ним, Top-5 совпал на 7 запросах. Это не ANN и не испытание 5–10 тыс. реальных строк или параллельной нагрузки на таком объёме. |
| **4. Качество поиска** | **Отчёт проверен, качество пока не принято.** [Замороженная проверка на 50 реальных описаниях](../DEVELOPMENT_LOG.md#21-ноября-отдельный-прототип-серверного-поиска): индекс содержит 18 из 59 подтверждённых целей; из 118 запросов с известным ответом покрыты 36. У гибрида Top-1 14/36, Top-5 27/36 среди покрытых; 24/30 посторонних запросов вернули карточки. [Отдельное правило фильтрации отклонено](https://github.com/veitnemed/watchbane/commit/ae7e632ace53896c52876f10df0ef14f47026d37): в независимой проверке потеряло 3 попадания Top-5 при допуске 1. Рабочие пороги не менялись. [Диагностика кандидатов](../DEVELOPMENT_LOG.md#22-ноября-где-поиск-теряет-нужный-фильм) нашла пять отказов до поиска, ни одного пропуска цели в списках кандидатов среди 31 допущенного и четыре потери после отбора. На 50 описаниях это не основание углублять поиск. [Узкое исправление примера «полиция ему не верит»](https://github.com/veitnemed/watchbane/commit/74f6dc013d91b313ab16b0272a599a3bf97112c7) не изменило метрики замороженной проверки. |
| **5. Клиент и согласие** | **Принят Linux loopback; Windows-клиент не принят.** Qt на реальном тестовом срезе получил результат без локальных E5, JSONL и ключа, сохранил фильм и показал его после перезапуска. [Ограничение частоты](https://github.com/veitnemed/watchbane/commit/134978625d5676c7dc47ced896feb3f2bc9a3345) опционально: 429 отдельно от занятого слота 503. [Qt-обработка](https://github.com/veitnemed/watchbane/commit/edc4dd603712b9d5bfa45f61ae921fcef6209804) показала подтверждённую паузу 6 с, без автоматической отправки; повтор прошёл только после нового ручного согласия. 173 целевые Linux-проверки. [Обе сборки Windows Server на edc4dd6](https://github.com/veitnemed/watchbane/actions/runs/45029210500) собраны и запущены; это не клиентская Windows. Обычный поиск и коллекция остаются локальными. |
| **6. Эксплуатация** | **Частично, только лаборатория.** [Нативный ARM64 TCP](https://github.com/veitnemed/watchbane/actions/runs/45025925922/job/137218823976), одна FP32-сессия, две синтетические версии по 1 000 строк, 2 CPU / 2 ГиБ / без swap. 14/14 старых ответов успешны, 13 завершились во время построения новой версии; p50/p95 266/499 мс, пик 1,24 ГиБ. В том же бюджете [две отдельные сессии дали OOM](https://github.com/veitnemed/watchbane/actions/runs/45023718979/job/137212028021). Это локальные эксперименты, не внешний хостинг, HTTPS, SLA или изоляция процесса при сбое. |
| **7. Пакет и выпуск** | **Потребительский выпуск заблокирован.** [Точная проверка исходного ZIP](https://github.com/veitnemed/watchbane/actions/runs/45028173036) и [Windows Server CI](https://github.com/veitnemed/watchbane/actions/runs/45028173055) прошли на [bae210a](https://github.com/veitnemed/watchbane/commit/bae210a52dc034ef90532daf06e9ed1622b7011f). Постоянные кредиты TMDB показываются в Qt без ключа; неподтверждённый растровый логотип исключён из будущих пакетов, но это не разрешение на распространение. ZIP с исходниками не содержит готового Windows EXE/весов/каталога. Отдельная чистая Windows 10/11 с обычным пользовательским запуском не проверена. [Preview 5](https://github.com/veitnemed/watchbane/releases/tag/story-search-preview.5) остаётся опубликованным исходным preview; нового релиза нет. |

**Стоп-условия приёмки оператора**

- **Не запускать живой TMDb** без авторизованного доступа и подтверждения прав на предполагаемые получение, частное хранение и индексацию. Для [микропробы](../TMDB_LIVE_MICROPROBE.md) нужны датированные источники, точные хеши и отдельный защищённый файл авторизованного ключа; 401, 403 или 429 прекращают прогон. Два тайтла не доказывают полноту или права публикации.
- **Не открывать внешний сервис** без явных прав на выдачу метаданных и изображений, проверенной атрибуции, включая официальный разрешённый логотип, HTTPS, лимитов, восстановления и согласованного бюджета. Локальное ограничение процесса не является публичным шлюзом.
- **Не объявлять готовую Windows-сборку или полный TMDb** до воспроизводимой проверки точного распространяемого пакета на чистой Windows 10/11 без Python/модели/каталога/ключа у клиента: русский сюжет → реальные результаты → сохранение → перезапуск. Отдельно подтвердить права на данные и фактический объём индекса; при отсутствии доказательств остаётся только эксперимент.
