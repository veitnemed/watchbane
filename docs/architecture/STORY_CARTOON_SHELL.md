# Два раздела и светлая оболочка — 2026-11-19

Владелец заменил задачу полировки тёмного интерфейса: новая видимая оболочка — только **Поиск** и **Коллекция** в одном окне. Исторические планы и предыдущие архивы не переписаны. Это интерфейсный срез поверх проверенных поиска, профильного векторного кэша и ограниченного TMDb импорта.

## Что изменилось

Кремовый фон, тёмный контур, один жёлто-оранжевый акцент. Оригинальный векторный кинобилет с лупой (`desktop/images/story_ticket.svg`) нарисован для проекта, без внешних изображений. Он есть только в пустом поиске; после запроса остаются поле и результаты. Короткие примеры кликабельны. Карточки выделяют название и дословный фрагмент описания, полный сюжет раскрывается отдельно. Локальный постер используется только если безопасный существующий путь найден старым offline resolver; HTTP/UNC, неподходящий формат, файл >8 МБ и изображение >16 млн пикселей не декодируются. Без постера — явный спокойный placeholder. Сеть для постеров не вызывается.

Видимых вкладок строго две (английские названия Search/Collection сохранены для английской настройки). Старые рекомендации, фильтры и настройки остаются реализованными, но не добавляются в QTabWidget и не показываются по registry.focus. Внутренние callbacks/идентификаторы сохранены. Удаления данных и миграции схемы нет.

Параметры источника/пула/модели не представлены отдельной формой или вкладкой. На пустом каталоге остаётся вторичная кнопка TMDb. Если модель не подключена или произошла ошибка модели, доступен контекстный выбор существующей папки; модель не скачивается автоматически. Ключ вводится только после явного импорта через прежний диалог. Ранжирование, retrieval, embeddings, кэш и запросы к TMDb не менялись этим срезом.

Коллекция имеет простой список карточек и переключатели Сохранено / Смотрел / Скрыто. Используются прежняя загрузка записей и title-state/dataset сервисы: скрыть, вернуть, отметить просмотренным, оценить, удалить после подтверждения. Поиск по названию внутри коллекции и прежний сценарий добавления названия доступны. Legacy WatchedTabView сохранён как адаптер, но его сложная панель не отображается. Контекстные диалоги добавления названия приведены к светлой палитре.

## Проверено

Реальные Linux Qt процессы: пустая главная; поиск через FP32 E5 по трём оригинальным вымышленным описаниям в временном локальном каталоге; Сохранить; открытие коллекции; закрытие и повторное создание окна с сохранённой записью. Выполнено при 1 и 1.25. Все шесть PNG главная/выдача/коллекция открыты и визуально проверены: нет наложений, первые действия и фрагменты читаются. Это **Qt offscreen**, не Windows и не live TMDb. Временный каталог нужен для проверки настоящего сохранения: встроенное 30-историйное демо по-прежнему не записывается в библиотеку.

При размере окна 1280×1000 верх первой карточки: 210 px на масштабе 1, 259 px на 1.25. Предыдущий реально снятый тёмный экран: 420/540 px. В старой выдаче использовалось встроенное демо, в новой — маленький synthetic QA каталог для сохранения; это сравнение компоновки, а не качества ранжирования или идентичного набора результатов.

Клавиатура: Tab к кнопке поиска, Space по примеру и раскрытию сюжета, Enter для запроса, Ctrl+L для возврата в поле, Escape для возврата фокуса. Проверены ошибки модели/импорта, отрицательный запрос, пустой запрос, отсутствие сети в демо. Проверены скрыть→вернуть, сохранить→смотрел, оценка, отмена и подтверждение удаления, поиск коллекции и вызов старого сценария добавления названия.

## Ограничения и ручная Windows-проверка

Исходный ZIP, не EXE. Windows фактически не запускался. На Windows проверить запуск из SOURCE_PREVIEW.md, Ctrl+Tab/Tab/Enter/Ctrl+L, системные 100/125%, путь модели с кириллицей, чистый профиль без токена, сохранение и переоткрытие коллекции, контекстное добавление названия, отмену импорта и модальные подтверждения. Не переносить личную базу без копии и не снимать секреты.

Сохраняются ограничения E5/корпуса, холодной памяти/загрузки, отсутствия live TMDb прогона и ошибок старой suite. Коллекция пока строит карточки для загруженных записей целиком; большие личные библиотеки здесь не измерялись. Legacy UI объекты ещё создаются скрыто для совместимости; визуальное упрощение не означает уменьшения startup RAM. Полная локализация новых текстов за пределами русскоязычной версии — отдельный долг.

Команды pytest относятся к полному checkout/патчу; передаваемый source ZIP предназначен для запуска и не содержит полный тестовый корпус. Добавление по названию переводит к новой записи в «Смотрел»; возврат из коллекции обновляет текущий поиск с учётом изменённых статусов. Ошибка сервиса удаления явно показывается без потери записи.

Финальный полный Linux-прогон: 1760 passed / 25 failed / 8 skipped. Набор failure IDs совпадает с предыдущим доставленным каталожным срезом; новых падений нет. 69 целевых тестов с настоящей локальной E5 прошли.

## Следующий срез: сохранение без исчезновения результата

Кнопка «Сохранить» теперь меняется на «В коллекции». Карточка остаётся на той же
позиции и сохраняет открытый сюжет; краткий фрагмент не дублирует развёрнутый
текст. При повторном поиске статус читается из SQLite. Неудавшаяся запись
оставляет кнопку активной. Прежние «Смотрел» и «Скрыть» по-прежнему выводят
результат из выдачи, без случайной замены.

Проверка: Qt/Linux при 100% / 125%, запрос «серийный убийца» по временному
локальному каталогу из 50 реальных описаний TMDb, E5 FP32; «Декстер», полное
описание, сохранение, коллекция, повторный поиск и переоткрытие. На кадрах
нет наложений, действия видны, русский текст читается. Проверено без запросов к
TMDb API; тестовые описания и модель не входят в source ZIP.

Коллекция теперь строит до 24 карточек на странице, а поиск по названию
фильтрует сразу весь выбранный раздел. Длинные синопсисы свернуты по умолчанию.
Проверены переходы вперёд, сброс страницы при смене запроса, поиск с последней
страницы и корректировка номера страницы после уменьшения списка. Проверка
на 121 синтетической записи при 100% / 125% отделена от сквозной проверки E5.
Макет коллекции также просмотрен при 100% / 125% на 31 сохранённом тайтле в
изолированном тестовом профиле: кнопки навигации остаются видны, фрагменты
умещаются, повторного появления onboarding или настройки пула нет.
