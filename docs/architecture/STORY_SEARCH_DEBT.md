# Поиск сюжета: измеримый долг после source preview

1. **Качество события и роли.** Тематическая близость не означает наличие ограбления, побега или тайны. Сначала фиксировать отдельный независимый набор коротких тем и подробных условий, с контрастными героями/конфликтами. Измерять retrieval Recall@40 отдельно от ранжирования Top-1/5. Если цель есть в top-K, исправлять rerank; если нет при наличии фактов в описании — исследовать обучение на отдельном train наборе. Никаких порогов по текущему holdout и никаких NLI-весов в этой версии.
2. **Масштаб и холодный запуск.** Есть один RAM-индекс и кэш passage-векторов. Проверка 12 описаний не предсказывает скорость большого каталога. Независимый Linux FP32 probe родительского ревью: 273 строки (39 описаний + синтетические суффиксы), около 42 с и 1,7 ГиБ peak; параллельная нагрузка возможна. Следующий этап — измерить 100/1000/10000 разрешённых описаний, RSS и UI heartbeat; рассмотреть отдельный процесс и версионированный дисковый кэш с явным управлением приватностью. Не сканировать TMDb целиком.
3. **UI responsiveness.** Работа вынесена в QThread, ввод доступен, индекс переиспользуется. На локальном smoke выявлена пауза heartbeat ~1,3 с при холодной загрузке; QThread не гарантирует отсутствие GIL-задержек. Отменяется между пакетами, не внутри ONNX вызова. Полностью отзывчивое закрытие/загрузка требует дополнительного измерения.
4. **Windows.** Проверить обычный запуск Python 3.13, FP32 на CPU без AVX512, масштаб 1/1.25, DLL/память/Unicode-пути, затем отдельно упаковывать EXE. Linux не закрывает этот пункт. Пробный zip — исходники.
5. **Каталог и данные.** Текущий адаптер читает существующий локальный пул; свежие пустые установки имеют только синтетическое демо. Широкий легальный источник/индекс, обновления, лицензирование и языковое покрытие — отдельный этап. Прикладной поиска API без токена не обещается.
6. **Отрицания и языки.** Распознанные маркеры исключений честно отклоняются. Это не полный парсер логики. RU/EN smoke мал; нужен независимый межъязычный набор и ручная проверка неизвестных результатов.

История V1 и результат ухудшения Top-1 от экспериментального sentence rerank сохранены. Пробная версия использует RRF без этого rerank; фрагменты извлекаются лишь для финальных карточек и никогда не меняют их порядок.
