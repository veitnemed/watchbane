# Стартовый каталог TMDb: операторская подготовка

Этот инструмент создаёт **отдельный локальный** JSONL из настоящих записей TMDb. Он не запускает приложение, не читает личную библиотеку, не меняет сохранённые карточки и не скачивает модель. Не запускается автоматически при старте. Нужны действующие учётные данные TMDb в уже поддерживаемой Watchbane конфигурации или переменных окружения; сам токен не передаётся аргументом и не попадает в каталог или журнал.

```text
python -m tools.qa.build_story_starter_catalog --through 2026-11-19 --checkpoint ./tmdb-starter.checkpoint.sqlite3 --output ./tmdb-starter.jsonl
```

Если токена ещё нет в конфигурации, добавьте `--ask-token` и введите его локально в скрытом приглашении терминала. Не передавайте токен как параметр или в чат.

Для продолжения запускайте ту же команду (тот же файл и параметры); только один процесс на контрольную точку. Страницы фиксируются по завершении, прерванная страница повторится. При заполнении плана итоговые 5 000 записей (2 500 фильмов и 2 500 сериалов) записываются атомарной заменой файла. При исчерпании доступных страниц программа выходит с кодом 2, не создаёт новый итоговый файл и сохраняет checkpoint; при ошибке выходит с кодом 1, при Ctrl+C — 130. Существующий JSONL остаётся прежним до полного успешного экспорта. Для другого плана (например, если нужно повысить лимит страниц) начните с нового checkpoint.

## Как формируется выборка

TMDb Discover: по очереди фильмы/сериалы, десятилетия с 1960-х и семь жанровых групп на каждый тип. Внутри сегмента запрос отсортирован по числу голосов, а не общему тренду популярности; по умолчанию минимум 10 голосов и до 12 страниц на сегмент. Это сбалансированная стартовая выборка по двум типам, не репрезентативная выборка по странам или обязательная точная квота на каждый жанр: пересечения и пустые сегменты нормальны. Даже с фиксированной датой страницы TMDb не заморожены, поэтому независимые сетевые запуски могут отличаться.

### Охват десятилетий в начале нового запуска

Обычный режим `decade-major` оставлен как раньше: в первом круге идут все жанровые группы 1960-х, затем 1970-х и т. д. Уже начатые контрольные точки продолжаются исходной командой, без смены режима.

Для **новой** контрольной точки можно выбрать `--order decade-interleaved`:

```text
python -m tools.qa.build_story_starter_catalog --through 2026-11-19 --order decade-interleaved --checkpoint ./tmdb-spread.checkpoint.sqlite3 --output ./tmdb-spread.jsonl
```

Пары запросов «фильм, сериал» проходят разные десятилетия уже в начале, со сдвигом жанровой группы на каждом следующем десятилетии. При периоде 1960–2026 первые 14 запросов именно к Discover покрывают семь десятилетий, оба типа и по семь групп каждого типа; возможные дополнительные запросы английских описаний в это число не входят. Это **порядок запросов**, а не гарантия записей в каждом сегменте. Пустые страницы, неполные описания и квоты по типу могут повлиять на фактический охват. Для продолжения сохраняйте флаг, дату и параметры плана; несовместимый режим отклоняется до сетевых запросов.

Источник текста: русскоязычный Discover с проверкой минимальной длины и преобладания кириллицы. При отсутствии пригодного текста запрашиваются только английские Details одного объекта; перевод не синтезируется. Поле `language` — локаль источника с проверкой алфавита, не полноценное определение языка. Нет запроса Details для каждой карточки. Взрослый флаг и явные сигналы блокируются, но Discover не содержит полный набор полей Details, поэтому этот экспорт не заменяет последующую проверку перед показом. Повторы объединяются по типу и ID, а разные фильмы с одинаковым названием остаются отдельными.

## Формат и использование

Одна строка UTF-8 JSON на запись: `key`, `media_type` (`movie` / `tv`), `tmdb_id`, `title`, `overview`, `year`, `language` (`ru-RU` / `en-US`), `source` (`tmdb`), `discover_bucket`, `genre_ids`, опционально `poster_path`. Такой файл можно прочитать как отдельный источник для локального поиска и отдельно построить векторный индекс. Записи сами по себе не импортируются в личный профиль. Не публикуйте выгруженные описания и изображения без проверки подходящих условий использования. Официальные описания API: [Discover movie](https://developer.themoviedb.org/reference/discover-movie), [Discover TV](https://developer.themoviedb.org/reference/discover-tv), [FAQ и атрибуция](https://developer.themoviedb.org/docs/faq).

## Проверка в интерфейсе отдельно от личного профиля

Preview читает готовый JSONL напрямую, а не загружает его в пул или
коллекцию. В интерфейсе файл можно выбрать через «Файл каталога…» на текущий сеанс. Действия «Сохранить», «Смотрел» и «Скрыть» относятся только
к явно выбранному профилю. Для испытаний укажите новый временный профиль:

```sh
python preview.py --check --catalog /private/catalog.jsonl
python preview.py --catalog /private/catalog.jsonl --model-dir /path/to/e5 --profile /private/watchbane-smoke-profile
python -m tools.qa.benchmark_story_seed --catalog /private/catalog.jsonl --model-dir /path/to/e5 --profile /private/watchbane-benchmark-profile
```

Создание векторов выполняется при первом поиске. Повторный запуск теста с тем же
benchmark-профилем проверяет существующий кэш. QA выводит число входных и
индексированных строк, счётчики кэша, время и ID результатов, без исходных
описаний. Сверяйте покрытие с ожидаемыми тайтлами отдельно от ранжирования.
Не публикуйте контрольную точку, JSONL или модель вместе с исходниками.

В JSONL также сохраняется `origin_country`, список доступных кодов стран происхождения, только если TMDb передал его в Discover или в уже необходимых Details. Страна не выводится из языка описания. Итоговый отчёт содержит `by_locale`, `tv_russia_origin`, `tv_unknown_origin` и `unusable_overview_count`. Последний считает уникальные обработанные записи с непригодным текстом на обеих локалях; на старом checkpoint без полной истории такого счётчика значение `null`. Старые строки без страны остаются неизвестными, а не получают страну задним числом.

### Программный прогон с лимитом попыток

Сборщик позволяет подставить отдельный `DetachedTmdbTransport` через `build_catalog(..., detached_transport=...)`. Это не новый CLI-флаг и не изменение обычной загрузки. Источник ключа передаёт вызывающий код; ключ не пишется в отчёт. `transport_attempts_this_run` считает обращения к сетевому транспорту, `api_requests_this_run` также учитывает логическую операцию, которую лимит мог остановить до сети.

При остановке с причиной `budget_exhausted`, `throttled` или ошибкой транспорта остаются только завершённые страницы. Уже существующий JSONL не перезаписывается неполным результатом. Продолжение использует тот же checkpoint и новый экземпляр транспорта с выбранным бюджетом; офлайн-проверка сравнивает конечные байты с непрерывным сбором. Это не общий таймер, ограничение размера профиля или доказательство пригодности большого реального каталога.
