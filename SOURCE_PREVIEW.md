# Текущий preview: Поиск + Коллекция + постеры

Светлая мультяшная оболочка с двумя разделами. Поиск начинается с одного поля и примеров; коллекция показывает сохранённое, просмотренное и скрытое. Технических вкладок нет. На пустом каталоге доступен явный TMDb импорт; модель выбирается существующей папкой только через контекстный диалог, без скачивания. Старые архивы неизменны. Подробности и проверка кадров: `docs/architecture/STORY_CARTOON_SHELL.md`.

Постеры видимых карточек загружаются асинхронно только с HTTPS image.tmdb.org и сохраняются в локальный кэш профиля. При отсутствии сети остаётся placeholder; поиск не ждёт картинки. Модель и изображения в ZIP не включены. Подробнее: `docs/architecture/STORY_POSTERS.md`.

# Watchbane: source preview поиска по сюжету

Это пробная Qt desktop версия, не релиз и не Windows EXE. Проверена на Linux/Python 3.12 с Qt offscreen. Windows-команды ниже подготовлены, но Windows-запуск не проверен. Главная функция — поиск по доступным локальным описаниям. Широкого каталога в архиве нет.

## Windows (PowerShell, из распакованной папки)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-preview.txt
.\Start-Preview.cmd
```

Без модели можно сразу попробовать явно обозначенный ограниченный словарный поиск на 30 вымышленных историях. Это не оценка качества E5. Требуются Python и доступ к PyPI при ручной установке зависимостей; приложение ничего не устанавливает.

Для настоящего смыслового поиска отдельно подготовьте официальную multilingual-e5-small. Команда ниже выполняет явное скачивание около 487 МБ, проверяет закреплённую ревизию и SHA256; прочитайте условия MIT на странице [издателя](https://huggingface.co/intfloat/multilingual-e5-small). В архиве весов нет.

```powershell
.\.venv\Scripts\python.exe -m tools.qa.download_story_model --destination ..\watchbane-e5 --variant fp32 --accept-download
.\Start-Preview.cmd --model-dir ..\watchbane-e5
```

Можно выбрать уже подготовленную папку модели кнопкой в приложении. Нужны `onnx/model.onnx` и `onnx/tokenizer.json` из закреплённой ревизии в `candidates/story_model_manifest.py`. CPU-specific INT8 VNNI на Windows намеренно не принимается. FP32 граф переносимый, но это не доказательство работоспособности конкретного Windows-ноутбука.

## Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-preview.txt
.venv/bin/python preview.py --check
.venv/bin/python preview.py --model-dir /path/to/watchbane-e5
```

Опциональные модельные зависимости отделены в `requirements-story.txt`; `requirements-preview.txt` включает базовые и модельные зависимости. Для fallback достаточно `requirements.txt`. `--check --model-dir ...` проверяет импорты, файлы и реальный inference, не открывая окно.

## Каталог и профиль

По умолчанию preview создаёт отдельный `.preview-profile` рядом с исходниками (для другой папки используйте явный `--profile`; унаследованный `WATCHBANE_DATA_DIR` не выбирается). Не указывайте рабочую библиотеку для первых проб: сделайте копию всей папки данных закрытого Watchbane и передайте её:

```powershell
.\Start-Preview.cmd --profile C:\Watchbane-test-profile --model-dir ..\watchbane-e5
```

Существующий локальный пул с описаниями подхватывается автоматически, без настройки вкусов или пула. Если физический пул пуст — показывается демо; если все реальные записи скрыты/просмотрены/без описания — пустое состояние. Демо никогда не заменяет скрытую карточку и не записывается в библиотеку. Сохранить/смотрел/скрыть используют существующее хранилище. Прежние реализации остаются в коде; видимая оболочка теперь состоит только из поиска и коллекции. Добавление по названию доступно внутри коллекции. Для онлайн-функций действуют прежние настройки; главный сюжетный поиск локальный и не запрашивает TMDb-токен.

## Поведение preview

- «Сохранить» не убирает карточку из выдачи: она отмечается «В коллекции».
  Полный сюжет раскрывается в карточке и не сворачивается при сохранении.
  При повторном поиске сохранённое состояние читается из коллекции.

- Поиск: E5 + текстовый TF-IDF, слияние рангов. Без скрытого sentence rerank и без строгого фильтра ролей для коротких тематических запросов.
- Явные тип и год выпуска ограничивают выдачу; «фильм или сериал» разрешает оба. Распознанные исключения пока отклоняются с объяснением, произвольная логика отрицаний не обещается.
- «Возможные совпадения» означает тематическую близость, не подтверждение каждого события. «Из описания» — дословный фрагмент локального источника, не доказательство соответствия.
- Индекс повторно используется в одной сессии; смена набора/модели или «Обновить описания» перестраивает его. В текущем следующем срезе векторы описаний сохраняются внутри активного профиля в `story_vectors_v1`; запросы и исходные тексты не сохраняются. Удаление этой папки при закрытом приложении очищает производный кэш. Детали и Windows-checklist: `docs/architecture/STORY_VECTOR_CACHE.md`. Ранее доставленный ZIP остаётся версией без дискового кэша.
- Первый поиск показывает «индексируем описания», работает в QThread. Можно вводить следующий запрос, выполняется последний введённый. Холодная загрузка библиотек/модели всё ещё может кратко задержать Qt; она требует заметной памяти. Закрытие запрашивает отмену между пакетами, текущий ONNX inference мгновенно не прерывается.

Проверки, сравнительный smoke и ограничения: `docs/architecture/STORY_SEARCH_V1.md`. Отдельный следующий этап: `docs/architecture/STORY_SEARCH_DEBT.md`. Ни личная база, ни TMDb-синопсисы, ни модель в пакет не включены. В архиве есть `SOURCE_MANIFEST.json` с хешами исходников; это локальная пробная сборка, а не подписанный дистрибутив.

## Новый срез: заполнение каталога из TMDb

На главной теперь есть «Заполнить каталог из TMDb» и число доступных описаний. Демо по-прежнему работает без ключа и сети. Только нажатие кнопки открывает существующую маскированную форму авторизации, если ключ ещё не настроен; успешная проверка запускает импорт. Можно вернуться к поиску без авторизации.

Импорт берёт умеренную выборку до 15 фильмов и 15 сериалов: русский сначала, английский fallback явно отмечается. Он не отправляет ваш сюжетный запрос и не загружает библиотеку на сервер. После завершения поиск обновляется без рестарта; повтор не дублирует прежние ID. Отмена/ошибка до сохранения не меняет каталог. Отмена ожидает завершения текущего сетевого вызова. После окончательного сохранения поздняя отмена уже не откатывает импорт.

Новый архив содержит исходники этого среза и локального векторного кэша. Ранее доставленный ZIP остаётся неизменным. Три иллюстрации передаются отдельно: это реально работающий Linux Qt с E5 и вымышленным демо, не живой TMDb импорт. Сквозной импорт проверен через mock; для живой проверки нужен ваш легитимный токен, не включённый в пакет. Подробности: `docs/architecture/STORY_CATALOG_PREVIEW.md`.

## Карточка и большая коллекция

В коллекции 24 карточки на страницу; строка поиска проверяет все названия,
а не только открытую страницу. Длинное описание сокращено до фрагмента,
полный текст открывается в той же карточке.
