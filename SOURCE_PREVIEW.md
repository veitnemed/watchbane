# Watchbane: поиск по сюжету, source preview 2

Это предварительная версия настольного Qt-приложения в виде исходников, не готовый Windows EXE. Она начинает работу с отдельным пустым профилем. В архиве нет готового кинокаталога, вымышленных карточек, выгрузок TMDb и постеров фильмов, ключей, личных профилей и весов модели. Пустой каталог не выдаёт результатов.

## Первый запуск

Windows PowerShell, из распакованной папки `Watchbane`:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Start-Preview.cmd
```

Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python preview.py --check
.venv/bin/python preview.py
```

Python и зависимости устанавливаются пользователем; Watchbane ничего не устанавливает сам. Профиль preview хранится в `.preview-profile` рядом с программой. Для отдельной папки передайте `--profile /путь/к/новому-профилю` (на Windows — через `Start-Preview.cmd`). Для первой проверки не указывайте рабочую библиотеку; если нужна существующая коллекция, сначала сделайте копию закрытого профиля.

## Откуда берутся реальные описания

- На пустом экране используйте **«Заполнить каталог из TMDb»**. Импорт по явному запросу использует ваш ключ TMDb и ограничен выборкой до 15 фильмов и 15 сериалов. После первой загрузки **«Пополнить из TMDb»** добавляет новую порцию без дублей из ограниченного числа страниц; это не импорт всего TMDb. Описания запрашиваются сначала на русском; при необходимости используется английский. При недоступности API пустое состояние остаётся честно пустым. Импорт не отправляет поисковый запрос.
- Если у вас уже есть локальный снимок TMDb формата Watchbane JSONL, передайте `--catalog /путь/к/снимку.jsonl`. Сначала можно выполнить `preview.py --catalog /путь/к/снимку.jsonl --check`: это проверяет формат, но не импортирует снимок в библиотеку. Снимок формата Watchbane не является произвольным JSON-ответом TMDb. Содержимое снимка не входит в дистрибутив.
- Локальные описания из выбранного профиля также доступны для поиска; чужой каталог не загружается скрытно.

Без модели используется ограниченный словарный поиск по доступным описаниям. Тематическое совпадение не подтверждает каждое событие или роль; текст «Из описания» относится только к исходному синопсису.

## Необязательная локальная модель E5

Для поиска по смыслу установите зависимости из `requirements-preview.txt` вместо базового файла или дополнительно из `requirements-story.txt`. Затем подключите существующую папку проверенной модели через доступную в интерфейсе настройку или флаг `--model-dir`. Для отдельной подготовки переносимого FP32-варианта официальной [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) можно явно запустить из папки приложения:

```text
python -m tools.qa.download_story_model --destination ../watchbane-e5 --variant fp32 --accept-download
```

Используйте Python активированного виртуального окружения. Команда скачивает около 487 МБ и проверяет SHA-256 файлов закреплённой ревизии; сама программа не запускает скачивание. `preview.py --check --model-dir /путь/к/модели` проверяет локальный inference. Для поиска при готовых данных Интернет не нужен; постеры при наличии адреса запрашиваются отдельно, их отсутствие не мешает поиску.

## Проверка архива

`SOURCE_MANIFEST.json` содержит хеши файлов и идентификатор исходного Git-коммита; рядом с ZIP публикуется SHA-256 всего архива. Это контроль целостности, не цифровая подпись. На Windows:

```powershell
Get-FileHash .\Watchbane-story-search-preview.2-source.zip -Algorithm SHA256
```

Сравните результат с соседним файлом `.sha256`. Windows-команды подготовлены, но нативный Windows-запуск этой source-сборки не подтверждён.
