# Watchbane: поиск по сюжету, source preview

Это предварительная версия настольного Qt-приложения в виде исходников, не готовый Windows EXE. Она начинает работу с отдельным пустым профилем. В архиве нет готового кинокаталога, вымышленных карточек, выгрузок TMDb и постеров фильмов, ключей, личных профилей и весов модели. Пустой каталог не выдаёт результатов.

## Первый запуск

Windows PowerShell, из распакованной папки `Watchbane`:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Start-Preview.cmd
```

Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python preview.py --check
.venv/bin/python preview.py
```

Python и зависимости для ZIP с исходниками устанавливаются пользователем. Профиль preview хранится в `.preview-profile` рядом с программой. Для отдельной папки передайте `--profile /путь/к/новому-профилю` (на Windows — через `Start-Preview.cmd`). Для первой проверки не указывайте рабочую библиотеку; если нужна существующая коллекция, сначала сделайте копию закрытого профиля.

## Откуда берутся реальные описания

- На пустом экране используйте **«Заполнить каталог из TMDb»**. Импорт по явному запросу использует ваш ключ TMDb и ограничен выборкой до 15 фильмов и 15 сериалов. После первой загрузки **«Пополнить из TMDb»** добавляет новую порцию без дублей из ограниченного числа страниц; это не импорт всего TMDb. Описания запрашиваются сначала на русском; при необходимости используется английский. При недоступности API пустое состояние остаётся честно пустым. Импорт не отправляет поисковый запрос.
- Если у вас уже есть локальный снимок TMDb формата Watchbane JSONL, нажмите **«Файл каталога…»**. После проверки поиск использует только этот файл, не добавляя его записи в профиль. Чтобы вернуться к обычному каталогу, выберите **«Вернуться к каталогу профиля»** в том же меню. Выбор файла действует в этом сеансе. Для явного запуска из терминала передайте `--catalog /путь/к/снимку.jsonl`. Сначала можно выполнить `preview.py --catalog /путь/к/снимку.jsonl --check`: это проверяет формат, но не импортирует снимок в библиотеку. Снимок формата Watchbane не является произвольным JSON-ответом TMDb. Содержимое снимка не входит в дистрибутив.
- Локальные описания из выбранного профиля также доступны для поиска; чужой каталог не загружается скрытно.

Без модели используется ограниченный словарный поиск по доступным описаниям. Тематическое совпадение не подтверждает каждое событие или роль; текст «Из описания» относится только к исходному синопсису.

## Необязательная локальная модель E5

Для поиска по смыслу установите зависимости из `requirements-preview.txt` вместо базового файла или дополнительно из `requirements-story.txt`. На экране поиска нажмите **«Подключить поиск по смыслу…»**, затем **«Скачать и установить (~487 МБ)»**. Только после подтверждения Watchbane скачает два закреплённых файла официальной [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small), проверит SHA-256 и запомнит модель для этого профиля. Отмена или ошибка не меняет действующий режим. Для первого скачивания нужен интернет, но ключ Hugging Face не нужен.

Модель не содержит сюжетов: отдельно подключите каталог. После этого поиск работает локально, без интернета; постеры при наличии адреса запрашиваются отдельно, их отсутствие не мешает поиску.

Для заранее подготовленной модели в том же окне выберите **«Выбрать готовую папку…»** или используйте флаг `--model-dir`. Выбор в интерфейсе сохраняется; флаг переопределяет его на текущий запуск. **«Перейти на поиск по словам»** отключает модель для профиля. Ручная подготовка переносимого FP32-варианта из активированного виртуального окружения:

```text
python -m tools.qa.download_story_model --destination ../watchbane-e5 --variant fp32 --accept-download
```

`preview.py --check --model-dir /путь/к/модели` отдельно проверяет локальный инференс. Проверка общей процедуры установки E5 на GitHub Windows runner не превращает этот архив исходников в установщик Windows.

## Проверка архива

`SOURCE_MANIFEST.json` содержит хеши файлов и идентификатор исходного Git-коммита; рядом с ZIP публикуется SHA-256 всего архива. Это контроль целостности, не цифровая подпись. На Windows:

```powershell
Get-FileHash .\Watchbane-story-search-preview.N-source.zip -Algorithm SHA256
```

Замените `N` на номер скачанного превью и сравните результат с соседним файлом `.sha256`. Список платформ, проверенных для конкретной версии, указан в её Release Notes.
